# AI Recommendation System

## Project Overview

This project is a simple AI Recommendation System developed using Python. The system recommends courses to users based on their interests by matching user preferences with course categories.

## Features

* User preference-based recommendations
* Similarity score calculation
* Top course suggestions
* CSV-based datasets
* Data visualization using charts
* Easy-to-understand recommendation logic

## Technologies Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset Files

* users_200.csv
* courses.csv

## How It Works

1. Load user and course datasets.
2. Select a user by User ID.
3. Compare user interests with course tags.
4. Calculate similarity scores.
5. Display top recommended courses.
6. Visualize recommendations using charts.
